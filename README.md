# TDS-project1-telegram-data-analyst-bot

On `/start`, the bot collects the user's name, age, and profile photo, then requests their location and phone number using Telegram's share buttons. Completed profiles are saved to Supabase Database, and photos are uploaded to Supabase Storage. No user profile data depends on Render's temporary filesystem.

## Supabase setup

1. Create a Supabase project and open **SQL Editor**.
2. Run this SQL:

```text
create table public.user_profiles (
	id bigint generated by default as identity primary key,
	created_at timestamptz not null,
	chat_id bigint not null,
	telegram_user_id bigint not null,
	username text,
	first_name text,
	last_name text,
	name text not null,
	age integer not null,
	photo_path text not null,
	latitude double precision not null,
	longitude double precision not null,
	phone_number text not null
);
```

3. Open **Storage**, create a bucket named `user-photos`, and keep it private.
4. Open **Project Settings > API** and copy the **Project URL** and **service_role key**.
5. Add these Render environment variables:

```text
SUPABASE_URL=https://your-project.supabase.co
SUPABASE_SERVICE_ROLE_KEY=your_service_role_key
SUPABASE_BUCKET=user-photos
```

The service-role key must only be stored in Render environment variables; never commit it to GitHub. View user records in **Supabase > Table Editor > user_profiles**. View photos in **Supabase > Storage > user-photos**.
